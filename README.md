# ChargeUA

Адаптивний лендинг національної мережі швидкісних електрозарядок ChargeUA. Веб-застосунок містить інтерактивний калькулятор вартості й часу зарядки, фільтри типів конекторів (Type 2, CCS 2, CHAdeMO), інтерактивну мапу зарядних станцій, систему бронювання слотів та адаптивну форму зворотного зв'язку з клієнтською валідацією (RegEx + доступне модальне вікно).

## Локальний перегляд

Відкрийте `index.html` у сучасному браузері (Chrome, Firefox, Edge, Safari). Для завантаження тайлів мапи Leaflet та шрифтів потрібне активне підключення до Інтернету.

## Публікація

* **GitHub Pages:** автоматичний деплой з кореня (`/`) гілки `main`.
* **Netlify:** безперервна інтеграція (CI/CD) з кореневого каталогу репозиторію. Параметри збирання відсутні, оптимізація та кешування налаштовані через `netlify.toml`, `_headers` та `_redirects`.

## Технології

* HTML5 (семантична розмітка, мікродані Schema.org)
* CSS3 (CSS Custom Properties, Flexbox, CSS Grid, медіа-запити)
* JavaScript (ES6+, модульна архітектура, асинхронні запити)
* Leaflet API (картографічний сервіс станцій)

## Структура проєкту

* `index.html` — головна сторінка лендингу з семантичною структурою;
* `css/style.css` — таблиця стилів, адаптивна верстка та теми;
* `js/calculator.js` — модуль динамічного розрахунку вартості й кіловат-годин;
* `js/map.js` — ініціалізація інтерактивної мапи електрозарядок;
* `js/validation.js` — клієнтська валідація форми зворотного зв'язку (RegEx) та керування модальним вікном;
* `assets/` — графічні ресурси (SVG-іконки, оптимізовані зображення станцій);
* `_headers` — політики безпеки CSP та HTTP-заголовки кешування статики;
* `_redirects` — правила маршрутизації та обробки сторінок помилок;
* `netlify.toml` — дескриптор конфігурації платформи розгортання Netlify.
